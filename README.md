## Welcome to When Last Login

[When Last Login](https://whenlastlogin.com) is a lightweight WordPress plugin that allows you to see active users according to their last login time/date. Simply activate the plugin and you're ready to go!

This plugin adds a custom "Last Login" column to your WordPress users list, showing a human-readable timestamp for each user. Sort users by their last login time to quickly identify active and inactive members.

## Features

* **Last Login Tracking** - Show when a user last logged into your site with human-readable timestamps (e.g., "2 hours ago", "3 days ago")
* **Sortable User List** - Sort users by last login time (ascending/descending) in the WordPress admin
* **Dashboard Widget** - View top 3 users by login count in your admin dashboard
* **Login History Table** - Access detailed login records under "When Last Login" > "All Login Records"
* **IP Address Tracking** - Optionally record user IP addresses on login
* **Paid Memberships Pro Integration** - Adds a "Last Logged In" column to the Members List (requires PMPro 1.8+)
* **Two Factor Authentication Support** - Integrates with the Two Factor plugin
* **Developer Friendly** - Includes hooks and filters for custom integrations
* **GDPR Compliant** - Built-in privacy exporter and eraser for user data

## Installation

### From WordPress.org (Recommended)

1. Go to Plugins > Add New in your WordPress admin
2. Search for "When Last Login"
3. Click Install Now and activate the plugin

### Manual Installation

1. Download the plugin ZIP from [WordPress.org](https://wordpress.org/plugins/when-last-login/)
2. Go to Plugins > Add New > Upload Plugin
3. Upload the ZIP file and activate

### From GitHub (Development Version)

1. Download the current development ZIP: `https://github.com/Yoohoo-Plugins/when-last-login/archive/dev.zip`
2. Extract and upload to `/wp-content/plugins/when-last-login/`
3. Activate the plugin

**Note:** Remove `-dev` from the folder name after extraction.
